# بوت الدردشة المجهولة — Anonymous Chat Bot

بوت تيليغرام للدردشة المجهولة بين شخصين، مع مطابقة ذكية حسب معايير يحددها الأدمن.
يدعم العربية والإنجليزية تلقائياً (حسب لغة كل مستخدم).

## مميزات البوت

- ملف شخصي عند أول دخول: الاسم (مخفي)، الجنس، الدولة، المحافظة، تاريخ الميلاد
- حساب البرج الفلكي تلقائياً من تاريخ الميلاد
- تاريخ الانضمام = لحظة أول دخول، ويظهر للطرف الآخر (بالأيام في الشهر الأول، وبالسنوات والشهور بعدها)
- أزرار: 🔍 ابحث عن أنثى / 🔍 ابحث عن ذكر
- مطابقة عشوائية منظمة بمعايير (يتحكم فيها الأدمن فقط، من داخل البوت):
  - تقارب العمر (أقصى فرق بالسنوات)
  - تقارب التقييم (من 5 نجوم)
  - تقارب المنطقة السكنية (نفس الدولة +2 نقاط، نفس المحافظة +3 نقاط)
  - خيار إلزامية نفس الدولة
- تقييم بعد كل دردشة (1-5 نجوم) ويأثر على المطابقات المستقبلية
- زر إبلاغ: يمنع المطابقة المستقبلية مع الشخص المُبلَّغ عنه ويرسل تنبيهاً للأدمن

## خطوات التشغيل

### 1) إنشاء البوت
1. افتح تيليغرام وابحث عن @BotFather
2. أرسل /newbot واتبع الخطوات (اسم البوت + اسم مستخدم ينتهي بـ bot)
3. خذ التوكن (Token) اللي بيعطيك ياه

### 2) معرفة آيدي حسابك (لتصبح أدمن)
1. افتح @userinfobot وأرسل /start
2. خذ رقم الـ ID

### 3) تعديل الإعدادات
افتح ملف config.py وضع:
- BOT_TOKEN = التوكن
- ADMIN_IDS = [آيديك]

### 4) تشغيل البوت على جهازك (للتجربة)
```bash
pip install -r requirements.txt
python bot.py
```
خلّي الطرفية مفتوحة، وجرّب البوت من تيليغرام.

### 5) التشغيل الدائم (24 ساعة)
لازم الكود يضل شغال على سيرفر. أسهل الخيارات المجانية:
- **Render.com** أو **Railway.app**: ارفع المشروع كـ Background Worker
- أو **VPS** رخيص مع pm2: `pm2 start bot.py --name anonchat`

ملاحظة: البوت يستخدم Polling (بيسحب الرسائل) — ما بحاجة دومين ولا HTTPS.

## لوحة الأدمن
أرسل /admin داخل البوت (من حسابك فقط) لتتحكم بالمعايير:
- زيادة/تقليل أقصى فرق بالعمر
- زيادة/تقليل أقصى فرق بالتقييم
- تفعيل/تعطيل إلزامية نفس الدولة
- عرض الإحصائيات (مستخدمين / دردشات نشطة / بالانتظار)

## ملاحظات
- اسم المستخدم لا يظهر أبداً للطرف الآخر (مجهول بالكامل)
- قاعدة البيانات SQLite بتننشأ تلقائياً باسم anonchat.db
- تقدر لاحقاً تضيف: مطابقة حسب البرج، حد أقصى لمدة الانتظار، أو حظر دائم من الأدمن
